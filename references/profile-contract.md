# Generated profile contract

The generated file is a single portable wrapper:

```json
{"format": "neurodaily.profile", "version": 1, "config": {}}
```

`config` contains:

- `profile`: topic slug
- `disciplines`: the topic and its subtopics
- `global_keywords`: aliases and subtopics
- `search.query`: quoted boolean query
- `search.authors`: optional tracked scholar names
- `search.author_mode`: `intersect` or `track`
- `sources`: enabled source presets, including `conferences` and `google_news_zh`
- `windows`: lookback windows
- `policy_feeds`: optional policy/news RSS
- `journals`: user-approved field journals

No passwords, API keys, SMTP settings, recipient addresses or local paths.
